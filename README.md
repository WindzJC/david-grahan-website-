# Mr Grumblebum & Friends — David Graham website concept

A complimentary, author-specific homepage concept by Astra Productions for Australian children's author David Graham.

## Visual direction
**A playful storybook town**, not a generic author marketing template. Warm cream paper, cheerful yellow, coral and sea-glass blue, cut-out book covers, a hand-drawn Farleigh skyline, character-themed decorative icons and friendly editorial typography.

The site is a simple static Cloudflare Pages project (no build command, repository root output directory). Includes mobile navigation, an accessible book finder, mobile layout, reduced-motion handling, and no search indexing in the concept phase.
